- `exec_kubectl_cmd_safely`: read-only kubectl. Pass the full command string, e.g. `kubectl get deploy my-app -n shop -o yaml`. Write verbs are rejected. Non-interactive diagnostic `kubectl exec ... -- <read-only command>` is allowed; do not use it for repairs or state changes. Never use `-A`/`--all-namespaces`, API discovery commands, or `get --raw`. Inspect only the target namespace/resource from RCA or plan context.
- `bash_exec` / `code_exec`: local sandbox tools for filtering, parsing, or computing over saved tool outputs. They have no cluster credentials; never run kubectl inside them. Use `save_as` on kubectl only when output may be long or needs later processing.
