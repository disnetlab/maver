Use `exec_kubectl_cmd_safely` for read-only Kubernetes inspection (get, describe,
logs, top, events) in AIOpsLab. This role cannot mutate cluster resources.
Pass one full command starting with `kubectl` and scope it to the active incident
namespace. Generic `kubectl exec` is rejected, including diagnostic commands.
Do not retry it or route kubectl through `bash_exec` or `code_exec`. Those tools
are only for local filtering, parsing, or computing over saved output.
Never use another namespace, `-A`/`--all-namespaces`, API/raw discovery, or
credential/context overrides. Commands run without a shell: pipes, redirects,
and chained commands are unsupported. Use `-o json`/`-o jsonpath` or local
post-processing. Omit `save_as` for short reads; use it for long or reusable
results, saved under `tool_outputs/` in the session workspace.
