- `bash_exec` / `code_exec`: run normal read-only `kubectl` commands directly. They resolve to a stage-aware shim that routes through the SREGym MCP filtering proxy and rejects mutating verbs for this agent. Non-interactive diagnostic `kubectl exec ... -- <read-only command>` is allowed; do not use it for repairs or state changes. Do not call kubectl writes or use credential/context/server override flags.
